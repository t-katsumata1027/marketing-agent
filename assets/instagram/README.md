# Instagram投稿の共通素材

- `logeats-icon.png`: Log-Eatsの公式`public/icon-512x512.png`をそのまま複製。再描画せず、「Log-Eats」の文字と並べて配置する。
- `MPLUSRounded1c-Medium.ttf`・`MPLUSRounded1c-Bold.ttf`: M PLUS Rounded 1c。Google Fonts公式リポジトリ`ofl/mplusrounded1c/`由来。柔らかいゴシック調の本文・見出しに使用する。
- フォント配布元: https://github.com/google/fonts/tree/main/ofl/mplusrounded1c
- ライセンス: SIL Open Font License 1.1。本文は`OFL.txt`。著作権者の上流原本 https://github.com/coz-m/MPLUS_FONTS/blob/master/OFL.txt から取得した。

追加の画像生成APIや有料フォントは使用しない。料理は既存X用の確認済み原本写真を再利用し、文字・数値・公式ロゴだけを固定レイアウトで合成する。完成画像の台帳には使用フォントのSHA-256を保存する。
